Unit - 1️⃣

1 Create a webpage named college.html for your college
using HTML5 Semantic Tags and Text Formatting.
Your webpage should include :

● A <header> containing the college name and a
short tagline.
● A <nav> with links such as Home, About,
Courses, and Contact.
● A <section> describing your college.
● An <article> highlighting one course offered by
the college.
● A <footer> displaying copyright information.
● Use the following text formatting tags at least
once:
<h1>, <p>, <b>, <strong>, <i>, <em>, <u>
  
2 Create a webpage named multimedia.html to demonstrate
HTML multimedia elements. Your webpage should include :

● A hyperlink to the Google website that opens in a
new tab.
● An image with appropriate src, alt, width, and height
attributes.
● An audio player.
● A video player.
● An embedded Google Maps or YouTube video using
an <iframe>.

3 Create a Feedback Form named feedback.html using
HTML5. The form should collect feedback from users and
include the following fields :

● Full Name (Text)
● Email Address (Email)
● Age (Number)
● Date of Visit (Date)
● Mobile Number (Telephone)
● Website (URL)
● Overall Rating (Range Slider)
● Favourite Theme Color (Color Picker)
● Upload Screenshot (File Upload)

Also include:
● Appropriate labels for every field.
● Submit and Reset buttons.

4 Create a Contact Us Form named contact.html using
HTML5 form validation.
The form should contain the following fields :

● Name
● Email
● Mobile Number
● Subject
● Message (Textarea)

Apply suitable HTML5 validation using :
● required
● placeholder
● pattern
Use appropriate validation for:
● Name (Only alphabets)
● Email (Valid email format)
● Mobile Number (10 digits)

Also include :
● Submit button
● Reset button
Finally, write 2–3 sentences explaining the importance of
HTML5 form validation.

Unit - 2️⃣

1 Create a webpage named Portfolio.html, which contains
information about you. Include following information like :

● Display your name. Apply <h1> tag. Align it to the
center. Apply color #1b5e20 using inline CSS.
● Display your Email, Phone Number. Apply <h4> tag.
Align it to the center. Apply color #424242 using
inline CSS.
● A navigation bar using <nav> tags containing links
to Home, Blogs, and Contact.
● Write two paragraphs about yourself. Use internal
CSS and apply it to <p> tag with following rules:
○ font-size: 18px; font-family: Arial; color:
#00695c;
● Add a green colored button “Contact me” and apply
class property. Create an external CSS file named
style.css. Link it with Portfolio.html. Write CSS
rules to change the button’s background color to blue
when hovered.

2 Use CSS Selector and Typography on above Portfolio.html.
CSS rules should be written in external CSS file style.css.
● Apply below mentioned CSS Selector on tags :

○ Element Selector
○ Class Selector
○ ID Selector
○ Attribute Selector
○ Pseudo-Class Selector
● Apply proper font, color and typography on
paragraphs.

3 Use CSS Flexbox, Grid and Positioning on above
Portfolio.html. CSS rules should be written in external CSS
file style.css.

● Use appropriate Flex layout on <nav> tags
containing links.
● Apply appropriate CSS positioning to the “Contact
me” button.

Unit - 3️⃣

1 Create a Portfolio.html webpage.

● Display a welcome message using JavaScript.
● Declare variables using let and const to store your
name, age, and course.
● Display the stored information on the webpage using
document.getElementById().
● Create a button named Show My Details.
● When the button is clicked, display your name, age, and
course on the webpage.

2 Create a webpage named Result.html.

● Create three input fields to accept marks for three
subjects.
● Calculate the total marks and percentage using
JavaScript operators.
● Use an if-else statement to check whether the student
has passed or failed. Consider 40 marks as the passing
mark for each subject.
● Display the total marks, percentage, and result on the
webpage.

3 Create a webpage named Multiplication.html.

● Create an input field to accept a number.
● Create a button named Generate Table.
● Write a JavaScript function to generate the
multiplication table of the entered number from 1 to 10.
● Use a loop to calculate and display the table.
● Display the multiplication table on the webpage when
the button is clicked.

4 Create a webpage named Registration.html.

● Create a registration form containing Name, Email, and
Phone Number fields.
● Use the required attribute to make all fields compulsory.
● Write a JavaScript function to validate the form when
the Submit button is clicked.
● Check that the name is not empty and the email contains
a valid email format.
● Display an appropriate success or error message on the
webpage.
● Use JavaScript event handling to perform the validation.
